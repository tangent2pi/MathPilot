# MathPilot 产品重构基线 v1

## 目标

MathPilot 是一个面向学生与教师的数学学习产品：学生在这里开始一段练习、保留自己的解题过程、获得循序反馈，并知道下一步；教师在这里整理教学资料、检查内容质量、跟进学生进度。界面呈现用户要完成的事情，不要求用户理解 Agent、数据库或服务拓扑。

本基线是前端重构的约束，同时保留 Pi Agent、原始资料、OCR 证据、K/T/E/R、SER/TSS/Continuity、Better Auth 与数据库权限等内部契约。

## 设计依据

- 先从用户需要和任务开始，再组织内容与页面；页面只保留完成任务所需的信息。
- 有顺序的工作使用任务步骤和明确状态，用户始终能看到“现在在哪里”和“下一步是什么”。
- 桌面使用固定侧栏，平板使用窄导航栏，手机使用底部导航；同一目的在不同尺寸保持同一名称和位置。
- 对话是 Agent 的主要表现形式；工具、引用、阶段和用量是消息的附属信息，默认收起。
- 文案从用户动作出发，使用句子式标题和主动动词；内部约束留在权限、验证和必要的帮助文本中。

## 用户角色与核心任务

### 学生

1. 了解今天最值得继续的学习任务。
2. 开始一轮短练习，逐题作答、写草稿、请求提示或追问。
3. 回看“我为什么得到这个结论”，查看证据与下一次复测。
4. 查看自己的学习计划、掌握变化和需要复习的内容。
5. 首次使用时完成一份简短学习设置。

### 教师

1. 添加教学资料，检查文件清单后确认开始处理。
2. 观察 KTQ 与 ER 的独立对话，必要时发送引导。
3. 按任务逐项复核题目、来源、题图、错因和规则。
4. 管理自己的内容、公共内容与学生绑定关系。
5. 查看学生进度、证据报告和学习计划。

## 信息架构

### 学生工作区

```
学习（首页）
├─ 继续学习 / 开始一轮
├─ 最近进度
└─ 今日建议

练习（题目与 Teaching Agent 对话）
报告（掌握、复测、错因、证据、计划）
我的（学习设置、绑定教师、账户）
```

### 教师工作区

```
工作台（需要处理的内容与学生动态）
├─ 待复核内容与学生诊断
└─ 最近内容任务
内容（资料、处理中任务、我的内容、公共内容）
学生（绑定关系、学生报告与计划）
设置（账户与工作区偏好）
```

复核直接进入工作台中的“需要你的判断”，避免为同一待办再设置一个重复一级入口。管理、导出、版本与评估属于设置中的二级工具。管理员能力通过权限显示可用操作，不改变普通教师的任务语言。

## 关键流程

### 学生首次使用

```
登录 → 学习设置 → 开始首轮练习 → 题目/草稿/对话 → 结论与下一题 → 报告
```

### 学生日常学习

```
学习首页 → 继续上次任务或选择复习 → 单题对话 → 题后总结 → 下一题/报告
```

### 教师内容处理

```
内容 → 添加资料 → 检查文件清单 → 确认开始处理 → KTQ → ER → 复核 → 发布
```

上传只创建“待确认资料集”。确认按钮是唯一进入处理阶段的用户动作；确认前可以移除文件、继续添加或离开页面。处理过程中可打开对应 Session，会话详情始终提供返回任务的入口。

## 页面职责

| 页面 | 唯一主要任务 | 次要内容 |
| --- | --- | --- |
| 学习首页 | 选择下一步学习动作 | 简短进度与今日建议 |
| 练习页 | 完成当前题并与 Agent 对话 | 草稿、题图、模型步骤 |
| 报告页 | 理解当前状态并决定下一步 | 证据、复测、计划 |
| 我的 | 修改学习设置与账户关系 | 绑定信息 |
| 教师工作台 | 判断并处理今天最重要的待办 | 复核队列、学生动态、内容任务 |
| 内容 | 创建并跟进一批资料 | 我的/公共内容筛选 |
| 学生 | 找到一个学生并继续支持 | 报告与计划 |
| Session | 阅读和继续一段 Agent 对话 | 工具、产物、阶段信息 |

## 状态和文案

所有长流程都使用统一的四类状态：待确认、处理中、需要操作、已完成；异常状态说明发生了什么和用户可以采取的动作。避免把系统实现、权限规则、数据库事实表或内部禁止事项写进页面主文案。

按钮使用结果动词：`确认并开始`、`继续处理`、`打开对话`、`开始复核`、`保存设置`。同一动作在不同页面保持同一名称。

## 响应式策略

- 1200px 以上：固定侧栏 + 内容区 + 可选详情栏。
- 768–1199px：窄侧栏或可收起导航，内容区保持单一阅读列。
- 767px 以下：底部导航，页面按单列排列；会话输入框固定在底部安全区上方。
- 所有交互目标至少 40px，保留可见键盘焦点，并尊重 `prefers-reduced-motion`。

## 验收

- 新用户只看页面标题和主按钮即可判断下一步。
- 上传后刷新仍停留在“待确认资料集”，不会自动开始 Agent。
- 内容任务、KTQ、ER 和教学 Session 都能进入同一会话界面并返回来源任务。
- 手机、平板、桌面下一级导航、主操作和状态表达一致。
- 页面可见文案中不出现比赛、评分门槛或内部实现说明。
