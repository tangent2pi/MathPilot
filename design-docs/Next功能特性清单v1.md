# MathPilot Next 链 · 功能特性清单

> 范围：web-next / api-next / pi-chat-runtime / learning-next / content-next / storage-next 构成的正式链路（旧链不在此清单内）。按"用户能用什么、系统能做什么"描述功能行为，不含内部实现。
> 落盘：2026-09-03，与产品重构基线/用户呈现形式等设计文档同库，供评审与功能验收对照。

## 一、学生功能

### 1. 对话与学习主界面

- **会话管理**：新建/搜索/重命名/归档会话；多会话并行切换；会话状态跨设备刷新后保持。
- **流式对话**：打字机式实时输出，支持 Markdown 与数学公式（KaTeX）排版。
- **过程可见**：可折叠查看模型的推理过程；模型读取文件、检索、执行学习动作等行为以中文动作摘要展示。
- **中断与控制**：回合进行中可取消；发送后不会误发重复消息。
- **语音输入**：浏览器支持听写时可直接语音作答。
- **未登录草稿保护**：访客输入的内容在登录后自动恢复，不丢失。

### 2. 一题一诊断闭环

- **题目卡**：单选/多选/填空/判断/解答等交互形式正式发题。
- **作答与回执**：提交后先出现"已保存"回执，再异步返回判定。
- **判定卡**：按评分要点给出对错结论，标注不确定性；答错不直接判死，可继续对话澄清。
- **完整/跳过**：可主动"完成本题"或跳过；跳过不作为失败证据。
- **透明出题**：题目卡说明"为什么选这道题"（已满足/未满足的目标与偏好）。
- **自动续接**：一题收尾后自动进入下一题选择，学生无感等待后台准备。

### 3. 助学内容

- **逐步推导教学卡**：模型产出经服务端验证的教学推导，按步骤展开（K12 数学版式），可作为学习材料回看。
- 普通文字解答、提示、讲解均可自由对话。

### 4. 图片与附件

- 拖拽/选择/拍照上传图片与文档；上传后进入只读的不可变存储，引用永久可靠。
- 图片作为题目/草稿证据被模型真实看见；失败重试不重复上传、不串台。

### 5. 学习上下文透明（侧栏面板）

- 实时显示：当前题、本轮学习目标（意图/活动）、已装入的该生学习观察、本轮参考过的内容快照（含版本与生成时间）、后台正在处理的操作。

### 6. 个人学习记录（学习空间五页）

- **概览**：下一步学习推荐 + 四项指标（进行中题目、到期复习、待验证错因、学习记忆条数）。
- **历史**：逐题作答记录回看（独立作答/提示依赖、判定结果），可跳回原对话。
- **科学状态**：
  - *掌握记录*：按知识点的掌握判断，附支持/反证证据与结论置信；
  - *保持（复习）状态*：是否到期、下次复习安排；
  - *错因情境*：哪些题型/情境下易犯的错因，当前处于待确认/已确认/在改进/已解决等状态。
- **学习记忆（画像注解）**：跨题整理出的稳定学习观察（适用场景、支持/反证）；学生可反馈"这不准确"或关闭个性化使用。
- **复习队列**：按保持率模型安排到期复习，一键开始（作为独立题目进入对话）。
- **证据包页**：单个判定的完整证据链（依据、替代解释、科学关系）；教师改判在此可见，原结论保留。

## 二、教师功能

- **班级管理**：建班、班级邀请码加入、查看成员、解除绑定。
- **学生全景**：逐生查看其概览/历史/科学状态/学习记忆/复习队列（同学生视图）。
- **诊断纠正**：对学生判定给出替代结论与理由后，系统**自动重放全部科学状态**（掌握/保持/错因），学生侧立即看到更正；AI 原结论与教师更正并存可追溯。
- **内容生产与复核**（对话式 KTQ/ER 管线）：
  - 上传资料 → 自动识别排版（OCR）→ Pi 会话抽取知识点/题型/题目候选 → **逐字段人工复核批注**（批准/要求修改/退回）；
  - 批准后进入错因与规则研究会话（带真实文献引用）→ 复核 → 进入规范内容库；
  - 教师退回批注后，**后台会话自动按批注重做**并生成新修订版本，无需人工重传。
- **内容库与发布**：五类规范内容（K/T/Q/E/R）可检索；发布成内容包版本、面向班级发布/撤回；范围控制（公共/教师私有/学生绑定）。
- **官方初始内容导入**：一次性导入已核验的官方章节数据（见第七节规模）。

## 三、学习内核（系统级功能特性）

- **三层量化分离**（可解释性核心）：
  - 掌握度：程序化知识追踪基准（模型判语义、程序定资格、成品算法算状态）；
  - 保持率：间隔复习安排，**只有独立完成的延迟复测**才更新，不确定时不伪造复习日期；
  - 错因证据：错因从"怀疑"到"确认/改进/解决/复发"的全程状态化跟踪。
- **证据纪律**：任何正式结论都须引用具体证据；低置信结论标"待观察/待复核"而非写入正式结论。
- **纠错即重放**：教师或系统纠正一律"追加替代 + 确定性重放"，历史结论永不覆盖删除。
- **画像整理（Dream）**：日常高频小更新 + 深度整理两节奏自动运行，产出的是带适用范围与证据来源的"学习观察注解"，可回滚；不覆盖科学数值（掌握/保持/错因）。
- **自适应选题**：按当前目标（覆盖薄弱、消歧、复习、训练等）与硬性约束（未见、可验证、前置满足）选下一题，选错时自我修正。
- **前台教学 / 后台整理分离**：学生发消息即刻由教学 Agent 处理；判定、画像、选题等自动在后台完成，不阻塞对话，故障可安全恢复。
- **内容与行为边界**：AI 在对话中只能发起"请求切题、修订选题意图、提交教学工件"三类受限动作，无法直接改分数/掌握度/数据库；正式卡片只能由系统生成，模型伪造不了结论卡。

## 四、对象与内容设施

- 图片/文件统一走**不可变版本化对象存储**：预签名直传/直下、防篡改校验、过期垃圾自动回收、按用途（题图/附件/头像/工件）分别约束类型与大小。
- 教学工件只在"验证通过"后对学生展示（当前支持逐步数学推导一类）。

## 五、安全与账号功能

- 注册/登录（Better Auth）、学生/教师角色、会话与资源级访问控制、租户隔离。
- 上传内容与历史一律按"数据而非指令"处理（防提示注入）。
- 前端教学会话固定为高推理强度与最小工具面；内容生产会话才有完整工具。
- 服务间通信带签名与防重放，外部无法伪造内部调用。
- 单机容器化部署一体（数据库 + 任务队列 + 对象存储 + 全部服务一套 compose 起）。
