> 权威来源：赛题参赛者版、原始用户会话、系统设计 v3.3、架构修订 v4。

## 0. 当前基线

- 当前 Compose 项目名为 `mathpilot-dev`；此前开发卷曾从空卷重建，随后教师已开始一轮真实内容管线验收，因而当前数据库不再为空。
- 当前暂存数据为 K=20、T=14、Q=84、E=15、R=15、题图资产=33、知识点—图片关联=111、已发布章节包=0；全部仍待教师复核和发布。
- 仅保留开发租户、四个业务身份，以及 Better Auth 的学生/教师初始账号。
- 默认启动不加载 `deploy/dev/seed.sql`；合成夹具只能通过 `fixtures` profile 显式加载。
- 空正式题库创建测评会在写 `AssessmentRun` 前返回 `409 content_library_not_ready`，不会留下孤立 run；旧 `web-test` 已删除，`apps/web` 是唯一前端入口。
- 赛题原始 PDF、OCR 参考稿和 Excel 模板是仓库输入材料，不属于运行数据库，未删除。

## 2. 可选加分项

| 加分项 | 当前实现 |
|---|---|
| 多轮追问区分错因 | 诊断后最多三轮 Pi 追问；可回答、跳过或绕过卡片直接文字回复；跳过不生成失败观测 |
| 目标分路径规划 | 画像访谈采集当前分/目标分/时间；分差进入 1–4 周任务密度、原难度与迁移任务排布 |
| 变式题或低一档巩固 | “专项巩固” AssessmentRun 在同维度已发布题中优先中低难度题；达标后可转迁移目标，不由模型临时编造正式题 |
| 教师端复核报告 | 教师可打开任一学生的快照、风险排序、保持率、错因、会话判答和原始观测；可改判观测并完整重放 |
| 迁移到新章节 | 内容工坊不限制五份或 PDF；资料批次、内容归档、按需 OCR、去重、复核和发布均为通用流程。Word/PPT 是否被上游 OCR 服务实际接受仍需单独实测 |
| 过程性数据沉淀 | 会话、作答、对话、草稿索引、Agent trace、观测、快照链、计划版本、保持率、错因状态均保留并可展示/导出 |

## 3. 内容与交付门

管理页实时计算以下正式库门槛，不读取仓库中的 CSV 充数：

- K ≥ 25；T ≥ 20；E ≥ 20；已发布 Q ≥ 80；R ≥ 20；
- 完整学生案例 ≥ 3；“完整”要求同时存在画像、已关闭诊断 Session、Dream 快照和学习计划；
- 内容发布可选择 `generic` 或 `competition_2026` 质量门。赛题门会在章节包发布事务内校验 K/T/E/Q/R 数量；
- 管理页可导出知识点、题型、错因、题目、诊断规则、学生案例和字段血缘 CSV，也可导出完整 JSON；
- 正式题目的答案、rubric、测量目标和 provenance 只走内部/教师接口，学生题面接口不会下发。

## 5. 仍未完成的提交物与验收

以下不是“再写一个页面”能完成，必须用真实运行证据收尾：

1. 对当前 84 道暂存题逐项复核来源、答案、选项、题图和测量维度。旧 KTQ 结果中的语义别名已由确定性兼容脚本全部改写为题目已声明的 K/T ID，并把旧值保存在 `legacy_measurement_targets` 和字段血缘中；该修复不替代教师逐题判断。
2. 当前 E/R 各 15，低于 `competition_2026` 的 E≥20、R≥20 门；只能基于资料证据补充并重新复核，不能为凑数生成。
3. 教师完成 K/T/Q 与 E/R 复核后发布 `competition_2026` 包，并复查去重、来源、模型用量和缓存率。
4. 生成并实际走完三类学生案例，运行 Dream，生成计划，确认三条自适应路径确实不同。
5. 建立黄金错因轨迹并记录诊断一致率；管理页目前能展示 golden 运行记录，但真实黄金集尚未产出。
6. 完成 README/部署说明、数据整理说明终稿、技术方案终稿和五分钟演示视频。
7. 实测上游 OCR 对 Word/PowerPoint 的支持；当前只证明了接口允许这些 MIME，不把它描述为已通过供应商验收。
8. 两级内容权限的 Schema、有效绑定、API/复核/导出范围、Agent 动态只读身份和前端绑定入口已实现，并通过事务型权限回归。仍待真实 Better Auth 多教师账号和发布/撤回操作验收。
9. 学生与教师的信息架构、统一 App Shell、内容确认流、持久 Chatbox、响应式布局和用户文案已重构；最终运行镜像已覆盖手机、平板、桌面截图、横向溢出、上传键盘入口与连续/拖放追加。完整人工无障碍审计（读屏、对比度和全站键盘遍历）仍需单独执行。

## 6. 比赛提交判定

代码功能面已覆盖内部验收矩阵的必选与可选能力；当前项目仍不能宣称作品已验收，因为真实内容复核、题图、三类学生路径、黄金评测、Word/PPT OCR 和视频尚无完整的新鲜运行证据。真实数据整理说明、演示材料和人工裁决齐备后，才允许标记提交就绪。
