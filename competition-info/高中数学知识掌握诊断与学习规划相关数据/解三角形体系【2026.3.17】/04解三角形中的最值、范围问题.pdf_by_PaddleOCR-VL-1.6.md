# 04 解三角形中的最值、范围问题

## 课程把控

## 必备知识

## 一、解三角形中的最值、范围问题的两种处理方法

(1) 角化边  $ \longrightarrow $ 利用基本不等式求最值、范围

余弦定理公式中有“平方和”和“积”这样的整体，一般可先由余弦定理得到等式，再由基本不等式求最值或范围，但是要注意“一正二定三相等”，尤其是取得最值的条件。

(2) 边化角  $ \longrightarrow $ 利用三角函数的性质求最值、范围

如果所求整体结构不对称，或者角度有更细致的要求（如规定为锐角三角形），用余弦定理和基本不等式难以解决，这时候可以转化为角的函数，消元后使得式子中只含有一个角，从而利用三角函数的性质求最值、范围，但是要特别注意三角形隐含角的范围、三角形两边之和大于第三边等。

【注意】其实“边化角  $ \longrightarrow $ 利用三角函数的性质求最值、范围”是一种通法，之所以还要学习第(1)种方法，是因为(2)比(1)会繁琐很多！

## 二、最值问题和范围问题的差别

(1) 最值问题和范围问题本质上是一种问题，因为求出最大值和最小值，就可以得出范围；

(2) 但是由于两种处理方法的差异, 具体如下:

①基本不等式一般只能得到最大值和最小值中的一个；

②基本不等式求最值，一般比利用三角函数的性质求最值要简便很多。

(3) 所以我们有以下经验：

①如果是最值问题，我们优先考虑以边为落脚点（角化边）利用基本不等式求最值；不可行时，再以角为落脚点（边化角）利用利用三角函数的性质求最值。

②如果是范围问题，我们大多采用以角为落脚点(边化角)利用三角函数的性质求范围；但是如果题目明显可以通过以边为落脚点(角化边)求范围，则可以利用基本不等式求范围，尽管此时求出的范围多为单边范围，如 $ [a,+\infty) $。

## 三、最值、范围问题的方法选择

我们就会疑惑，那看到一道题，该怎么判断用什么方法解题最合适呢？首先我们明确两种方法：①利用基本不等式；②利用三角函数的性质。

(1) 利用基本不等式的应用条件或形式：

①题目中的角度没有更细致的要求；

②题目中条件和结论表现为“三边一角”；

③题目中结论的整体结构对称，最常见的就是“a+b”和“ab”；

④利用角度的基本不等式的特殊题.

(2) 利用三角函数的性质的应用条件或形式：

总体来说，其实只要不是利用基本不等式基本就是利用三角函数的性质了，但这里我们还是做一个简单的分类：

①题目中的角度有更细致的要求，常见的有“锐角三角形”；

②题目中条件和结论表现为“多角”关系；

只含角的式子，如： $ \cos A + \cos B + \cos C $；

③结论的形式

含边的“齐次式”，如： $ \frac{a+b}{c} $， $ \frac{a^{2}+b^{2}}{c^{2}} $；

含边的“非齐次式”且整体结构不对称，如： $ 2a+b, a-b $.

#### 【注意】

①题目中的角度有没有更细致的要求是一眼就能看出来的，因此将其放在了第一点；

②上述应用条件或形式注意与后面的题目结合理解！

### 题型归纳

#### 【题型1】利用基本不等式的应用条件或形式

例1 在$\triangle ABC$中，角$A,B,C$的对边分别为$a,b,c$，已知$a^2+4b^2=c^2$，则$\sin A$的最大值为___。

【答案】$\frac{1}{4}$

【解析】已知  $ a^{2}+4b^{2}=c^{2} $，则  $ b^{2}=\frac{1}{4}(c^{2}-a^{2}) $，

所以由余弦定理$\cos A=\frac{a^{2}+c^{2}-b^{2}}{2ac}=\frac{a^{2}+c^{2}-\frac{1}{4}(c^{2}-a^{2})}{2ac}=\frac{5a^{2}+3c^{2}}{8ac}\geqslant\frac{2\sqrt{5}a\cdot\sqrt{3}c}{8ac}=\frac{\sqrt{15}}{4}$，

当且仅当$\sqrt{5}a=\sqrt{3}c$取等号，即$\cos A$的最小值为$\frac{\sqrt{15}}{4}$，

则根据$\sin^{2}A+\cos^{2}A=1$，可知$\sin A$的最大值为$\sqrt{1-\frac{15}{16}}=\frac{1}{4}$。

故答案为：$\frac{1}{4}$。

例2 [长沙长郡中学2025高一月考]$\triangle ABC$的内角$A,B,C$的对边分别为$a,b,c$，已知$(2c-a)\cos B-b\cos A=0$。

(1) 求角 B 的大小;

(2) 若  $ a + c = 1 $，求 b 的取值范围.

【答案】(1) $ \frac{\pi}{3} $; (2) $ \frac{1}{2}\leq b<1 $.

【详解】(1) 已知  $ (2c - a)\cos B - b\cos A = 0 $，

由正弦定理可得： $ 2\sin C\cos B - \sin A\cos B - \sin B\cos A = 0 $，

所以  $ 2\sin C\cos B=\sin(A+B)=\sin C $，

因 $C$ 为三角形内角，则 $\sin C \ne 0$，所以可得 $\cos B = \frac{1}{2}$，

又 $B \in (0, \pi)$，所以 $B = \frac{\pi}{3}$。

(2) 因为  $ B = \frac{\pi}{3} $,  $ a + c = 1 $,

由余弦定理可得  $ b^{2}=a^{2}+c^{2}-2ac\cdot\cos B=(a+c)^{2}-3ac $

因为 $ ac\leq\left(\frac{a+c}{2}\right)^2 $

所以  $ b^{2} \geqslant (a+c)^{2}-3 \times \left(\frac{a+c}{2}\right)^{2} = \frac{1}{4} $，

所以 $ b \geqslant \frac{1}{2} $，

又 $ b<a+c=1 $，

所以 $ \frac{1}{2}\leq b<1 $.

即 b 的取值范围为  $ \left[\frac{1}{2},1\right) $.

例3 [长沙周南中学2025高三月考]已知 $ \triangle ABC $中，角 $ A,B,C $所对的边分别为 $ a,b,c $，且 $ b\sin(A-C)=c\sin(B-A) $.

(1) 证明： $ b^{2}+c^{2}=2a^{2} $;

(2) 若  $ \triangle ABC $ 面积为  $ \sqrt{3} $，求  $ a $ 的最小值.

##### 【答案】(1)证明见解析；(2)2

【详解】(1)依题意，$\sin B(\sin A\cos C - \sin C\cos A) = \sin C(\sin B\cos A - \sin A\cos B)$，

即 $2\sin B\sin C\cos A = \sin A(\sin B\cos C + \sin C\cos B) = \sin A\sin (B + C) = \sin^2 A$，

$a^2 = 2bc\cos A = b^2 + c^2 - a^2$，故 $2a^2 = b^2 + c^2$。

(2)$S = \frac{1}{2}bc\sin A = \sqrt{3}$，故 $bc = \frac{2\sqrt{3}}{\sin A}$，

又由余弦定理得 $a^2 = 2bc\cos A$，故 $a^2 = \frac{4\sqrt{3}}{\tan A}$，

又 $\cos A = \frac{b^2 + c^2 - a^2}{2bc} = \frac{b^2 + c^2}{4bc} \geqslant \frac{2bc}{4bc} = \frac{1}{2}$，

故 $A \in (0, \frac{\pi}{3}]$，从而 $a^2 \geqslant \frac{4\sqrt{3}}{\sqrt{3}} = 4$，

即 $a > 2$，当 $b = a - 2$ 时等号成立，则 $a$ 的最小值为 2

即  $ a \geqslant 2 $，当 b = c = 2 时等号成立，则 a 的最小值为 2.

例5 [长沙长郡中学2021高三月考]$\triangle ABC$的内角$A,B,C$的对边分别为$a,b,c$，设$\sqrt{3}b\sin A=a(2+\cos B)$。

设 $ \sqrt{3}b\sin A = a(2 + \cos B) $.

(1) 求  $ B $;

(2) 若  $ \triangle ABC $ 的面积等于  $ \sqrt{3} $, 求  $ \triangle ABC $ 的周长的最小值.

【答案】(1)  $ B = \frac{2\pi}{3} $; (2)  $ 4 + 2\sqrt{3} $

【详解】(1) 因为  $ \sqrt{3}b\sin A = a(2 + \cos B) $,

所以  $ \sqrt{3}\sin B\sin A = \sin A(2 + \cos B) $,

因为  $ \sin A > 0 $, 所以  $ \sqrt{3}\sin B - \cos B = 2 $, 所以  $ 2\sin\left(B - \frac{\pi}{6}\right) = 2 $,

 $ \because B \in (0, \pi) $, 所以  $ B - \frac{\pi}{6} \in \left(-\frac{\pi}{6}, \frac{5\pi}{6}\right) $,

所以  $ B - \frac{\pi}{6} = \frac{\pi}{2} $,  $ \therefore B = \frac{2\pi}{3} $;

 $ \therefore b \geq 2\sqrt{3} $, 当且仅当  $ a = c = 2 $ 时取等号,

所以  $ \triangle ABC $ 的周长最小值为  $ 4 + 2\sqrt{3} $.

#### 【题型2】角度有更细致的要求

例1 [湖南五市十校教研教改共同体2024高二期中联考]已知a,b,c分别为 $ \triangle ABC $三个内角A,B,C的对边，且 $ 3a\cos C+\sqrt{3}c\sin A=3b $.

(1) 求 A;

(2) 若 a=2，且  $ \triangle ABC $ 为锐角三角形，求  $ \triangle ABC $ 周长的取值范围.

【答案】(1) $ \frac{\pi}{3} $; (2) $ (2+2\sqrt{3},6] $

【详解】(1) 由已知和正弦定理得  $ 3\sin A\cos C + \sqrt{3}\sin C\sin A = 3\sin B $，

又 $ \sin B = \sin(A + C) = \sin A \cos C + \sin C \cos A $,

 $$ \therefore\sqrt{3}\sin C\sin A=3\sin C\cos A, $$ 

又 $ \sin C \ne 0 $， $ \therefore \sqrt{3} \sin A = 3 \cos A $，有 $ \tan A = \sqrt{3} $，

又  $ A \in (0, \pi) $,  $ \therefore A = \frac{\pi}{3} $;

(2) $ \because a=2 $，且 $ A=\frac{\pi}{3} $

$\therefore$ 由正弦定理有$\frac{b}{\sin B}=\frac{c}{\sin C}=\frac{2}{\sin\frac{\pi}{3}}=\frac{4\sqrt{3}}{3}$，

从而  $ b=\frac{4\sqrt{3}}{3}\sin B $， $ c=\frac{4\sqrt{3}}{3}\sin C $，

 $$ \because\sin C=\sin(A+B)=\sin\left(\frac{\pi}{3}+B\right), $$ 

 $$ \begin{aligned}&\therefore b+c=\frac{4\sqrt{3}}{3}\Big[\sin B+\sin\Big(\frac{\pi}{3}+B\Big)\Big]\\ &=\frac{4\sqrt{3}}{3}\Big(\frac{3}{2}\sin B+\frac{\sqrt{3}}{2}\cos B\Big)=4\sin\Big(B+\frac{\pi}{6}\Big),\\ \end{aligned} $$ 

又$\triangle ABC$为锐角三角形，有$B\in\left(0,\frac{\pi}{2}\right)$，且$A+B=\frac{\pi}{3}+B\in\left(\frac{\pi}{2},\pi\right)$，$\therefore B\in\left(\frac{\pi}{6},\frac{\pi}{2}\right)$，$\therefore B+\frac{\pi}{6}\in\left(\frac{\pi}{3},\frac{2\pi}{3}\right)$，有$\sin\left(B+\frac{\pi}{6}\right)\in\left(\frac{\sqrt{3}}{2},1\right]$，故$b+c\in(2\sqrt{3},4]$，从而$\triangle ABC$周长的取值范围为$(2+2\sqrt{3},6]$。

例2 [长沙雅礼中学高三月考] 在$\triangle ABC$中，角$A,B,C$的对边分别为$a,b,c$，若$a\cos C+\sqrt{3}a\sin C-b-c=0$。

(1) 求 A;

(2) 若  $ \triangle ABC $ 是锐角三角形，c=4，求  $ \triangle ABC $ 面积的取值范围.

【答案】(1) $ A=\frac{\pi}{3} $; (2) $ (2\sqrt{3},8\sqrt{3}) $

【详解】(1) 由  $ a\cos C + \sqrt{3}a\sin C - b - c = 0 $，

可知  $ b = a \cos C + \sqrt{3} a \sin C - c $，

从而由正弦定理得  $ \sin B = \sin A \cos C + \sqrt{3} \sin A \sin C - \sin C $.

故 $ \sin A\cos C+\sqrt{3}\sin A\sin C-\sin C=\sin B=\sin(A+C)=\sin A\cos C+\sin C\cos A $

这就得到 $ \sqrt{3}\sin A\sin C - \sin C = \sin C\cos A $，

 $$ \sqrt{3}\sin A-1=\cos A. $$ 

此即  $ 1 = \sqrt{3} \sin A - \cos A = 2 \sin\left(A - \frac{\pi}{6}\right) $,

故 $ \sin\left(A-\frac{\pi}{6}\right)=\frac{1}{2} $

得 $ A-\frac{\pi}{6}=\frac{\pi}{6}+2k\pi $或 $ A-\frac{\pi}{6}=\frac{5\pi}{6}+2k\pi $，这里 $ k\in Z $.

结合  $ 0 < A < \pi $，就知道  $ A = \frac{\pi}{3} $

(3) 由正弦定理可得  $ b = \frac{c \sin B}{\sin C} = \frac{4 \sin(A + C)}{\sin C} = \frac{2 \sin C + 2\sqrt{3} \cos C}{\sin C} = 2 + \frac{2\sqrt{3}}{\tan C} $,

 $$ S_{\triangle ABC}=\frac{1}{2}b c\sin A=\frac{1}{2}b\cdot4\cdot\frac{\sqrt{3}}{2}=\sqrt{3}\cdot b=2\sqrt{3}+\frac{6}{\tan C}. $$ 

而因为 $ \triangle ABC $为锐角三角形，

故 $ \left\{\begin{aligned}0&<\frac{2\pi}{3}-C<\frac{\pi}{2}\\ 0&<C<\frac{\pi}{2}\end{aligned}\right. $

解得 C 的范围是  $ \frac{\pi}{6} < C < \frac{\pi}{2} $.

从而 $ \tan C $的范围是 $ \tan C > \frac{\sqrt{3}}{3} $

故  $ S_{\triangle ABC}=2\sqrt{3}+\frac{6}{\tan C} $ 的取值范围是  $ (2\sqrt{3},8\sqrt{3}) $.

#### 【题型3】利用三角函数的性质的应用条件或形式

例1 [长沙长郡中学2022高三月考] 在$\triangle ABC$中，角$A,B,C$所对的边分别为$a,b,c$，设$S$为$\triangle ABC$的面积，满足$S=\frac{\sqrt{3}}{4}(a^{2}+b^{2}-c^{2})$.

(1) 求角 C 的大小;

(2) 求  $ \cos A + \cos B + \cos C $ 的最大值.

【答案】(1) $ \frac{\pi}{3} $; (2) $ \sqrt{3} $

【详解】(1)由题意可知， $ S=\frac{1}{2}ab\sin C=\frac{\sqrt{3}}{4}\times2ab\cos C\Rightarrow\tan C=\sqrt{3}\Rightarrow C=\frac{\pi}{3} $；

(2) 由题, 可得  $ \cos A + \cos B + \cos C = \cos A + \cos\left(\frac{2\pi}{3} - A\right) + \frac{1}{2} $

 $ = \cos A + \left(-\frac{1}{2}\cos A + \frac{\sqrt{3}}{2}\sin A\right) + \frac{1}{2} = \frac{\sqrt{3}}{2}\sin A + \frac{1}{2}\cos A + \frac{1}{2} = \sin\left(A + \frac{\pi}{6}\right) + \frac{1}{2} $,

其中  $ A \in (0, \frac{2\pi}{3}) $, 则  $ A + \frac{\pi}{6} \in \left(\frac{\pi}{6}, \frac{5\pi}{6}\right) $,

所以当  $ A + \frac{\pi}{6} = \frac{\pi}{2} $, 即  $ A = \frac{\pi}{3} $ 时,  $ \cos A + \cos B + \cos C $ 有最大值  $ \frac{3}{2} $.

(2) 若 D 是 BC 上一点，且  $ \overrightarrow{CD} = 2\overrightarrow{DB} $，AD = 1，求  $ \triangle ABC $ 面积的最大值.

【答案】(1) $ A=\frac{\pi}{3} $; (2) $ \frac{3\sqrt{3}}{8} $.

【详解】(1)在$\triangle ABC$中，由$a\sin B=\sqrt{3}b(1-\cos A)$及正弦定理得$\sin A\sin B=\sqrt{3}\sin B(1-\cos A)$，因为$B\in(0,\pi)$，$\therefore\sin B\neq0$，则有$\sin A=\sqrt{3}-\sqrt{3}\cos A$，即$\sin\left(A+\frac{\pi}{3}\right)=\frac{\sqrt{3}}{2}$，由$0<A<\pi$，$\frac{\pi}{3}<A+\frac{\pi}{3}<\frac{4\pi}{3}$，得$A+\frac{\pi}{3}=\frac{2\pi}{3}$，所以$A=\frac{\pi}{3}$。

(2) 依题意,  $ BD = \frac{1}{3}a $,  $ DC = \frac{2}{3}a $, AD = 1,

在$\triangle ADB$与$\triangle ACD$中，分别由余弦定理得$\cos\angle ADB=\frac{DA^2+DB^2-AB^2}{2DA\cdot DB}=\frac{1+\frac{1}{9}a^2-c^2}{\frac{2}{3}a}$，$\cos\angle ADC=\frac{DA^2+DC^2-AC^2}{2DA\cdot DC}=\frac{1+\frac{4}{9}a^2-b^2}{\frac{4}{3}a}$，又$\cos\angle ADB=-\cos\angle ADC$，

于是  $ 3 + \frac{2}{3}a^2 - b^2 - 2c^2 = 0 $，则有  $ b^2 + 2c^2 - 3 = \frac{2}{3}a^2 = \frac{2}{3}(b^2 + c^2 - 2bc\cos A) = \frac{2}{3}(b^2 + c^2 - bc) $，整理得  $ 9 = b^2 + 4c^2 + 2bc \geqslant 4bc + 2bc = 6bc $，即  $ bc \leqslant \frac{3}{2} $，当且仅当  $ b = 2c = \sqrt{3} $ 时取等号，所以  $ \triangle ABC $ 面积的最大值为  $ S_{\max} = \frac{1}{2} \times \frac{3}{2} \times \sin \frac{\pi}{3} = \frac{3\sqrt{3}}{8} $。

【详解】(1)由题意得 $ \sin A+\frac{a^{2}+c^{2}-b^{2}}{2ac}=0 $，

 $$ f(B)=16\sin^{2}B+\frac{9}{\sin^{2}B}-19\geqslant2\sqrt{16\sin^{2}B\cdot\frac{9}{\sin^{2}B}}-19=5 $$

6.[长沙南雅中学2025高二月考]在$\triangle ABC$中，$a=c\cos B+\frac{1}{2}b$.

(2) 若 c=4，且  $ \triangle ABC $ 为锐角三角形，求  $ \triangle ABC $ 周长的取值范围.

所以由正弦定理可得，$\sin A = \sin C\cos B + \frac{1}{2}\sin B$，

又因为在$\triangle ABC$中，$\sin A = \sin[\pi - (B + C)] = \sin(B + C)$，

所以$\sin B\cos C + \cos B\sin C = \sin C\cos B + \frac{1}{2}\sin B$，

整理可得$\sin B\cos C = \frac{1}{2}\sin B$，又因为$0 < B < \pi$，$\sin B > 0$，

所以$\cos C = \frac{1}{2}$，因为$0 < C < \pi$，所以$C = \frac{\pi}{3}$。

因为$S_{\triangle ABC} = \frac{1}{2}ab\sin C = \frac{\sqrt{3}}{4}ab = 3\sqrt{3}$，所以$ab = 12$。

因为$a + b = 8$，所以由余弦定理可知，

$c^2 = a^2 + b^2 - 2ab\cos C = (a + b)^2 - 3ab = 64 - 3 \times 12 = 28$，

所以$c = 2\sqrt{7}$。

(2) 因为  $ c = 4 $，又由 (1) 可知  $ C = \frac{a}{3} $，所以  $ B = \frac{2\pi}{3} - A $，由正弦定理可知  $ \frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = \frac{4}{\sin \frac{\pi}{3}} = \frac{8\sqrt{3}}{3} $，所以  $ a = \frac{8\sqrt{3}}{3} \sin A $， $ b = \frac{8\sqrt{3}}{3} \sin B $，所以  $ \triangle ABC $ 的周长  $ a + b + c = \frac{8\sqrt{3}}{3} \sin A + \frac{8\sqrt{3}}{3} \sin B + 4 = \frac{8\sqrt{3}}{3} \sin A + \frac{8\sqrt{3}}{3} \sin \left( \frac{2\pi}{3} - A \right) + 4 = \frac{8\sqrt{3}}{3} \sin A + \frac{8\sqrt{3}}{3} \left( \frac{\sqrt{3}}{2} \cos A + \frac{1}{2} \sin A \right) + 4 = \frac{8\sqrt{3}}{3} \sin A + 4 \cos A + \frac{4\sqrt{3}}{3} \sin A + 4 = 4\sqrt{3} \sin A + 4 \cos A + 4 = 8 \left( \frac{\sqrt{3}}{2} \sin A + \frac{1}{2} \cos A \right) + 4 = 8 \sin \left( A + \frac{\pi}{6} \right) + 4 $。
