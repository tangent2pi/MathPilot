# Review-001：代码库对照设计 v3.3 的结构审查与清理记录

> 日期：2026-08-18
> 性质：agent 生成代码与设计文档（`design-docs/系统设计v3.3-…重构与结构审查.md` §2.4 模块清单、§4 角色与运行架构、§18 组装顺序）的偏差审查。
> 范围：`src/` 全部模块、`db/migrations`、`deploy/dev`、`tests/e2e`。不做行为功能新增，只做结构归位、去重复、去偏离。

## 1. 基线：设计 v3.3 §2.4 的模块清单

```text
apps/web-test（首期流程验证）        services/api, agent-runtime, content, learning, profile, review
packages/contracts（Schema+Provider 接口）  packages/providers/{model,ocr,search,media,explanation}
packages/sandbox（挂载/网络/资源/写区策略） packages/mastery  packages/provenance  packages/ui-sdk（后期生成）
```

设计核心理念（§0/§2.1/ADR-002）：四个边界上下文只交换版本化契约对象；**模块可独立替换、不共享私有结构**；Provider 接口在 contracts，**实现归 `packages/providers/*` 或 agent-runtime 宿主侧**（ADR-001 决策 3）。

## 3. 保留的骨架简化（阶段 A 合法形态，随阶段 B/C 落地，非本次范围）

按 §18 阶段 A"每个模块先有最小可运行实现，尚未完成的外部能力使用符合契约的 stub"，以下为有注释标注的有意简化：

- **Agent 工具面只有 `respond`**（§4.4 要求 `bash`+`search`）：沙箱与 Search Broker 属阶段 B，落地后接入；
- **learning `PILOT_QUESTIONS` 内置试点题**（§7.2"正式 Session 只读已发布章节包"）：dev 兜底，发布链路已以 content 为准；
- **单题状态机为单次提交直通**（§4.5 的 OBSERVE/WAIT/PROBE/TEACH/RETEST 未实现）：聊天追问与探针属阶段 C；
- **教师纠正复用原 TSS**（§11.2 要求重建双产物）：代码内已注释"真实模型接入后落地"；
- **`review_required` 不阻断物化**、**`runtime_chat_turn`/`infra_outbox`/`review_agent_trace` 尚无写者**、**Schema 运行时校验未接线**（契约文件已冻结，services 用内联校验）：审计与事件化属阶段 B；
- **api 无 SSE/WebSocket**（§2.4 网关职责）：阶段 B。

## 4. 审查通过项（无需改动）

- 四大边界服务齐备：content（暂存→KTQ/ER 双 Session→复核门→不可变发布+字段血缘）、learning（一题一 Session、模型主判、双产物、SLR 入 Dream 队列）、profile（EvidenceBundle→Dream 独立 Session→Validator→快照物化）、review（supersede+重放+修订 SLR）；
- ADR-004 写路径隔离成立：learning/review 不写 snapshot，snapshot 唯一写入方是 profile 的 Dream 物化；
- 不可变事件纪律（0006/0007/0008 触发器）、RLS 全量启用、SLR 修订谱系（session_id,ser_id 复合唯一 + supersedes）；
- 21 个契约 schema + 三组样例全部通过校验；BKT 内核与状态门槛对拍通过；
- 双产物结构、LR 区间表、Validator 四类检查（引用/LR 越界/双计数/算术可重算）与设计 §9.4 一致。

## 6. 复审补充（2026-08-18 用户复审意见后追加）

用户复审补充三条硬约束，均已纳入本次清理：

1. **多用户/租户隔离**：agent-runtime 任务 Session 创建时绑定 `x-tenant-id`，
   prompt/查询/销毁跨租户一律 403（`session_tenant_mismatch`）；PostgreSQL RLS +
   不可变事件触发器维持；api OIDC 路径 principal 一律来自服务端（学生强制自域、
   教师端点角色门）。沙箱按 tenant/student/session 隔离随阶段 B 落地。
2. **严禁任何回退方案**：learning 的 `PILOT_QUESTIONS` 内置兜底题与"通用 rubric"回退
   已删除——题目只读已发布章节包（设计 §7.2），未发布/不可达显式 404/502；试点题改由
   `deploy/dev/seed.sql` 以**已发布章节包**形式入种子（人工审定 + 血缘记录，设计 §7.3）。
   KTQ 血缘的片段关联改为抽取 Agent 声明（`source_fragment_id`）+ 存在性校验，
   删除轮转猜测。所有 Provider 失败路径显式 502/503，不伪造结果。
3. **AI 对话一律经 Pi Agent；行为控制走策略/Skills/工作区文件，不限制 Agent 循环**：
   任务提示从 TS 代码迁出到 `policies/`（`agent.md` 通用纪律 + `tasks/*.md` 任务策略 +
   `tasks.manifest.json` 注册表：prompt_version / 主辅模型角色单一来源）；agent-runtime
   启动装载、缺失即失败；prompt_version 随 trace 返回并写入血缘/判答/画像决策审计字段。
   Pi 本体零修改（仅用 pi-agent-core / pi-ai SDK 的扩展机制接入 scnet Provider 与任务提示）。
   skills 目录预留在 policies/ 下，与任务策略同一管理方式。
4. **Dream `review_required` 语义修正**：模型声明需复核的 Decision 升级教师复核
   （student_diagnosis 队列），不物化快照、不消费 SLR（设计 §9.3 送教师复核路径）。
