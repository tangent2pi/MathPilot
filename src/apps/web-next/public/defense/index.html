Case · 一个真实的作答瞬间

答案判对的那一刻，系统在过程里标了一处疑点

在 △ABC 中，已知 b=2，c=√6，B=45°，求 C。
由正弦定理：b/sinB = c/sinC
sinC = c·sinB / b = √3/2
∴ C = 60°（写到这里就停了……）
✓
答案：正确
⚠️ 过程疑点 · 只写 60°，漏了讨论
🔍过程抓包➔ 只看答案：✓ 放行
看过程：⚠️ 有遗漏
🔍 AI 判定 · 命中过程疑点
题型· 三角形个数判断

学生只写了 C = 60°——但 c·sinB < b < c 时本应存在 两解，他还漏掉了 C = 120°。结果判对，判别过程却缺失。

系统随即发起追问：「另一个角为什么舍去？」→ 判定到底算对了，还是只是碰巧？
传统看答案判对 → 打勾放行 → 疑点漏过
VS
MathPilot判过程 → 当场抓包 → 追问消歧 → 证据留痕

Why · 传统诊断的失效

01致命 · 痛点
