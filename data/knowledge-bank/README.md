# MathPilot 知识题库库（agent 可读文件库 · 每章一档）

教师上传练习资料 → `teacher` skill 结构化出"四库"（知识点 / 题型 / 题库样本 / 错因）→ 按**章节**落盘为独立目录，供抽题、测评、画像（BKT）读取。资料越多，本章 Excel 越大；章节越多，目录越多。

## 目录规范（每章一档）

```
knowledge-bank/
├── README.md                    # 本说明（索引 + 扩展规范）
└── <章节名>/                    # 例：解三角形/
    ├── 数学知识库_<章节名>[_版本].xlsx   # 四库 Excel（4 个 sheet，主档）
    ├── question_images_index.json        # 溯源：q_id ↔ 源 PDF/页/坐标（切图记录）
    └── 题目图片/                        # Q_XXX_001.png … 文件名即题目 ID，一一对应
```

- 新增章节：把 teacher skill 生成的 `<章节名>` 四库整个目录放入 `knowledge-bank/` 下即完成扩档，无需改本说明。
- 版本管理：Excel 文件名可带版本/日期后缀（如 `_完整版`、`_备份_20260902`），旧版保留不删，README 的"档内清单"记录当前生效档。

## 抽题口径（对接 BKT 测评，v0.1）

1. 学生/教师定位知识点：沿 `知识点库` 三级模块树（一级 → 二级 → 三级 → 知识点名称），落到 `知识点ID`。
2. 抽题：从 `题库样本` 过滤 `知识点ID = 目标`（可加 `难度`、`适合测评 = 是`），整题下发。
3. 作答观测（第一版）：**整题对/错 = 1 条二值观测**，写入该题 `知识点ID` 维度（评分点级拆分留待题库补 rubric 后升级）。
4. BKT 更新（与产品 `scientific-core` 同构，论文式 8-10）：

   - 参数集 `bkt-oatutor-prior-v1`（prior_only）：先验 π=0.3，失误 s=0.1，猜测 g=0.2，学习 τ=0.0
   - 答对 `P ← P(1−s)/[P(1−s)+(1−P)g]`；答错 `P ← Ps/[Ps+(1−P)(1−g)]`；结果四舍五入到千分位
5. 状态判定（独立观测 ≥2 后生效；<2 为 `insufficient_evidence` 只更新不下结论）：
   `p<0.4 weak` ｜ `p<0.8 learning` ｜ `p<0.95 possibly_mastered` ｜ `p≥0.95` 且有迁移证据才 `mastered`（追问/提示后作答不独立，不计观测）。
6. 画像记录：每知识点维度维护 `(p_mastery, state, independent_count, 最近观测序列)`，按产品 Dream/SER 规范落记录。
