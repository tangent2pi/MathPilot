# 学生诊断案例（交付物：≥3 个完整案例）

> 三个案例覆盖不同基础与目标分，展示"画像采集 → 测评（判答/错因追问）→ 双产物 →
> Dream 画像 → 报告与计划"的完整诊断路径。作答记录为演示路径样例；真实运行由
> 系统产生（用例可经 web-test/real-smoke 复现）。

## case_001 — 基础薄弱型

| 项 | 内容 |
|---|---|
| 学生画像 | 高一，当前分 60，目标分 90，每周 4-6 小时，无草稿设备 |
| 自认薄弱 | 正弦定理公式适用条件不清（K_SINE_RULE） |
| 预期诊断 | 判答 partial（公式用对但漏解数讨论）→ 错因归因候选 E_SSA_MISSING_OBTUSE → 补角追问卡 → 未闭合 → 待观察 |
| 期望报告 | K_SINE_RULE 学习中（0.4-0.8）、K_SSA 证据不足；复测估计不稳定 |
| 计划方向 | 周1 知识补讲+低一档练习 → 周2 原难度 → 周3-4 原难度+迁移 |

## case_002 — 公式会但分类讨论不全型

| 项 | 内容 |
|---|---|
| 学生画像 | 高二，当前分 95，目标分 115，每周 7-10 小时，触屏手写 |
| 自认薄弱 | SSA 解的个数讨论（K_SSA） |
| 预期诊断 | 判答 partially（只给锐角解）→ 归因 E_SSA_MISSING_OBTUSE → 补角判断题卡（可跳过）→ 答对闭合错因 → 双产物入队 |
| 期望报告 | K_SSA 学习中、错因 suspected→confirmed（一题证据+探针） |
| 计划方向 | 周1-2 原难度练习（分类讨论专项）→ 周3 迁移题（不同表征）→ 周4 延迟复测 |

## case_003 — 基础较好冲高分型

| 项 | 内容 |
|---|---|
| 学生画像 | 高三，当前分 120，目标分 135，每周 10+ 小时，纸面拍照 |
| 自认薄弱 | 最值范围问题的取等条件遗漏（E_SCOPE_* 类） |
| 预期诊断 | 判答 correct 或 partial → 覆盖/迁移目标 → 报告"可能掌握"边缘 → 迁移验证 |
| 期望报告 | K_SINE_RULE 可能掌握、K_SSA 已掌握（若两题独立成功+迁移） |
| 计划方向 | 目标分路径：高频题型巩固 → 综合迁移 → 限时训练 |
